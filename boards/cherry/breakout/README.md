# Cherry all-signal pogo breakout fixture

Cherryを上に載せ、裏面のJ2/J3/J5の穴へ下側からポゴを当て、全信号を治具外周のピンヘッダへ1対1で引き出すだけの治具です。

- J1: Cherry J2の24信号。2×24ピンで、各信号は2列とも同じネット。
- J2: Cherry J3の24信号。2×24ピンで、各信号は2列とも同じネット。
- J3: Cherry J5のSPI/CRESET/GND、1×6ピン。
- USB-CはCherry本体へ直接接続します。治具にはUSB回路を載せません。
- 囲み線はCherry外形、MH1--MH4は押さえ板/側面ガイド用です。

全54個のポゴを実装可能ですが、必要な信号だけ実装しても構いません。ポゴはFEINMETALL H100LA-7.6 + F10014B130G150を基準に、穴径1.75 mmで作っています。部品変更時は穴径を再確認してください。

J1/J2のピン番号はCherryのピン番号と同じです。J3はJ5のピン番号と同じです。
