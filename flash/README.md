# Flash tools

- [`cli`](cli/README.md): Rust `nmb` command-line programmer
- [`web`](web/README.md): pnpm, React, Tailwind CSS, and Rust WASM Web Serial programmer

Both implementations use the CDC ACM framing and flash format defined in
[`doc/flash.md`](../doc/flash.md) and [`doc/flash.ja.md`](../doc/flash.ja.md).
